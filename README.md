## 从结构到结果

- **建模与输入。** 编辑分子、晶体和片段，从二维结构生成三维初猜，准备 Gaussian 与 ORCA 输入。
- **构象与轨迹。** 组合采样、逐级优化和归簇，播放轨迹时查看逐帧连接、晶胞及冻结原子。
- **反应路径与后处理。** 运行适用的内坐标扫描、CI-NEB、FSM 或双端 GSM，分析 TS、振动、IRC 和波函数。

## 下载与使用

完整解压 Windows x64 便携包，运行 **Ester-Studio.exe**。首次启动请阅读许可并确认计算资源。2.1.2 内置 GFN0/1/2-xTB 与 GFN-FF 的运行环境。部分波函数分析按需配置 Multiwfn，运行 Gaussian 或 ORCA 作业时使用各自的外部程序。

<details>
<summary>项目兼容、外部程序和源码附件</summary>

- 2.x 新版支持载入该主版本的旧 `.es`，保存采用当前格式。已有 NET 结果可按原方法、能量、轨迹和来源查看与导出。神经网络势计算留待后续版本。
- g-xTB 从[官方发布页](https://github.com/grimme-lab/g-xtb/releases)获取，在 Settings 中选择和检测可执行文件。
- 本仓库提供软件介绍、展示资料和发行入口。完整产品源码发布在独立的 `Ester-Studio-v2.1.2-source-code.zip`。自动生成的 Source code 附件对应此介绍仓库。
